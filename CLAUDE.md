# Consignes pour les agents

- Lire `ARCHITECTURE.md` avant toute modification et respecter ses règles (couches, taille des fichiers,
  conventions, « où mettre quoi »).
- Toute modification se termine par `npm run check` (types + lint + tests) et `npm run format`.
- Une règle de gameplay modifiée ou ajoutée s'accompagne d'un test dans `tests/`.
- Commentaires et textes du jeu en français.
